# Results

The main results are in the format of $\texttt{conf\_jrpInitConf\_circuitConf.json}$ files. THe other results are in the other directories.

* **contourf_plots**: the 3-tensor data and its corresponding images in a colormap. More details on how these plots works on $\texttt{../results.ipnyb}$.
* **contour_plots** the contour plots that simplifies some information getted from the 3-tensor data. More details on how these plots works on $\texttt{../results.ipnyb}$.
* **csvs**: some numerical results in csvs format,
* **experiment_resuseOptimizedParameters**: this is a second experiment that arises from the TestQAOASolver experiment. Basically, it works by trying to reuse the optimized parameters for a particular instance in other instances.
